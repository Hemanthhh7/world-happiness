# Statistical Analysis and Trends in World Happiness

A Python/Google Colab project analysing national happiness scores and their relationships with economic and social indicators.

## Analysis included

1. **Distribution analysis** – histogram and KDE of national Life Ladder scores, with mean and median.
2. **Bivariate analysis** – scatter plot and fitted regression line for Log GDP per capita versus Life Ladder score, with Pearson correlation and R-squared.
3. **Correlation analysis** – Pearson correlation heatmap for happiness and six explanatory factors.

The report supplied with the project describes the period **2011–2017**. The code filters the data to that period before generating the three figures.

## Dataset

The original CSV was not attached to the conversation, so it is not included as a fabricated or reconstructed file. The notebook and Python script download the dataset from this public CSV mirror when run:

- [World Happiness Report dataset CSV](https://github.com/VStanys/CSV-WHR/blob/main/world-happiness-report.csv)
- [World Happiness Report official data-sharing page](https://www.worldhappiness.report/data-sharing/)

The CSV columns used are `year`, `Ladder score`, `Log GDP per capita`, `Social support`, `Healthy life expectancy at birth`, `Freedom to make life choices`, `Generosity`, and `Perceptions of corruption`.

Please check the dataset source and its terms before redistribution. The figures in `reference_plots/` are the three images copied from the user's supplied Word report; they are included only as visual references. The reproducible figures generated by the code are saved to `plots/`.

## Run in Google Colab

1. Open `world_happiness_analysis.ipynb` in Google Colab.
2. Run **Runtime → Run all**.
3. Ensure the Colab runtime has internet access so it can download the CSV.
4. The three generated charts will be saved in `plots/`.

## Run locally

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python analysis.py
```

## Important note

The statistical values shown in the report's supplied images are the values visible in those figures. Running this notebook recalculates the statistics from the linked CSV and may produce slightly different values if the dataset version or missing-value handling differs. Use the newly generated outputs consistently in the final report.
